## The joke

> Monday morning, my laptop offered to restore last week's tabs. I clicked yes — then realised it should've asked about my will to live first.

## The angle

Instead of reaching for the usual Monday props — the alarm, the coffee,
the traffic — the joke starts somewhere specific and ordinary: opening a
laptop on Monday morning and seeing the familiar "restore last week's
tabs?" prompt. That setup sounds harmless, even helpful. The turn is in
the second sentence. Saying yes to the tabs is easy; the thing that
actually needs restoring after the weekend is not in any browser window.
The punchline lands by swapping a small, technical restore for a much
bigger, human one, so the joke is about Monday morning itself, not just
a list of things wrong with it. Every word earns its place: two short
sentences, one setup, one twist, and nothing left over.

## How to run it

`main.py` uses only the Python standard library and makes no network
calls. It writes the single one-liner to `/output/entry.txt`:

```bash
python3 main.py
cat /output/entry.txt
```

The output is one line, well under the 200-character limit, and running
the program twice produces byte-identical output.
